🤖 Introduction

GTA VI Website Recreation is a frontend project inspired by the visual style and cinematic presentation of Grand Theft Auto VI.

The project focuses on recreating an immersive web experience through smooth animations, interactive elements, scroll-based transitions, and visually engaging layouts.

Built using React and GSAP, the website explores modern frontend animation techniques and motion-driven storytelling.

⚙️ Tech Stack

- React – Component-based architecture for building interactive user interfaces.
- GSAP – Advanced animations, timelines, and scroll-based interactions.
- Tailwind CSS – Responsive styling and utility-first CSS development.
- Vite – Fast development environment and optimized production builds.
- JavaScript – Application logic and interactive functionality.

🔋 Features

- 🎬 Cinematic Animations: Smooth and engaging entrance animations.
- ✨ Text Reveal Effects: Dynamic text animations for impactful visual presentation.
- 🌀 ScrollTrigger Effects: Animations synchronized with scrolling.
- 🌊 Parallax Scrolling: Layered movement for immersive visual depth.
- 📌 Pinned Sections: Scroll-controlled sections for cinematic storytelling.
- 🎥 Scroll-Synchronized Video: Video playback controlled by scroll progress.
- 🎨 Image Masking: Creative transitions and image reveal effects.
- 🔄 Animated Carousel: Interactive carousel with smooth transitions.
- 📱 Responsive Design: Adaptive layouts for different screen sizes.

🤸 Getting Started

Follow these steps to run the project locally.

Prerequisites

Make sure you have the following installed:

- Git
- Node.js
- npm

Clone the Repository

git clone <your-repository-url>
cd <your-project-folder>

Install Dependencies

npm install

Start Development Server

npm run dev

Open the local URL displayed in your terminal (usually http://localhost:5173) to explore the website.

Build for Production

npm run build
